# Prompts for real-looking menu photos
Use these in the **Gemini app** (gemini.google.com → ask it to create an image) or any image generator, or run `python generate_photos.py` to do all 20 at once with your API key.
Save each result as `images/<id>.jpg` (or .png). The app automatically uses a photo if it exists, otherwise it shows the drawn illustration. AI-generated food images should be labelled as illustrative in a real shop.
